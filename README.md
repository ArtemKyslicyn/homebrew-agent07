# Homebrew Tap for Agent07

Local AI Agent Orchestrator for macOS — DAG pipelines with GGUF models + OpenRouter.

## Install

```bash
brew tap ArtemKyslicyn/agent07
brew install --cask agent07
```

## Update

```bash
brew upgrade --cask agent07
```

## Uninstall

```bash
brew uninstall --cask agent07
```

## Requirements

- macOS 14+ (Sonoma)
- Apple Silicon (M1/M2/M3/M4)
- 8GB+ RAM recommended

## Features

- **Local LLM inference** — Qwen3, DeepSeek Coder, Llama via LLM.swift
- **Free cloud models** — OpenRouter with 28 free models (no payment)
- **DAG pipeline editor** — visual agent orchestration
- **20+ code tools** — Read, Edit, Bash, Grep, Glob, Patch, Git
- **MCP support** — Model Context Protocol servers
- **VS Code extensions** — host extensions in-app
- **Project indexing** — FTS5 BM25 + TF-IDF semantic search
